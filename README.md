# Ubuntu Cleanup

Simple cleanup script for Ubuntu Server.

The script removes:

- installed Snap packages
- `snapd`
- `cloud-init`
- `cloud-initramfs-copymods`
- `cloud-initramfs-dyn-netconf`
- Snap and cloud-init leftover files

## Important

The script **does not remove `/etc/netplan` configuration**.

This is intentional. On many Ubuntu servers, the existing Netplan configuration may have originally been generated by cloud-init but is still required for networking after cloud-init is removed.

## Quick install

Run directly from GitHub:

```bash
curl -fsSL https://raw.githubusercontent.com/igoron76/ubuntu-cleanup/main/ubuntu-cleanup.sh | sudo bash
```

## Download and run manually

```bash
curl -fsSLO https://raw.githubusercontent.com/igoron76/ubuntu-cleanup/main/ubuntu-cleanup.sh
chmod +x ubuntu-cleanup.sh
sudo ./ubuntu-cleanup.sh
```

## What the script does

1. Removes installed Snap applications.
2. Removes remaining Snap base/system packages.
3. Stops and disables `snapd`.
4. Purges the `snapd` package.
5. Purges `cloud-init` and related initramfs packages.
6. Runs `apt autoremove` and `apt autoclean`.
7. Removes Snap and cloud-init leftover files.
8. Verifies the result and displays the current network configuration.

## Requirements

- Ubuntu Server
- APT package manager
- systemd
- root privileges

Run the script as `root` or with `sudo`.

## Warning

Removing `cloud-init` should only be done when the server no longer depends on cloud-init for provisioning or future configuration.

Always make sure the server has a working persistent network configuration before removing cloud-init.

A reboot after cleanup is recommended.
